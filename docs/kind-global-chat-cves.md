# CVEs in kind-global-chat

Status date: 11 November 2026. Context `kind-global-chat`, Kubernetes v1.35.0.

This is the vulnerability inventory for images running in the cluster, plus the Kubernetes component versions Trivy could read from the API. It is separate from the posture report. `posture` keeps five example CVE ids on each `TRIVY-VULN` finding. This file is the full list.

Trivy 0.76.2, vulnerability database updated 2026-11-11 13:00 UTC. The command uses the current kubeconfig context:

```bash
trivy k8s --timeout 15m --disable-node-collector \
  --scanners vuln --report all --format json \
  -o cluster-cves.json
```

`--scanners vuln` is the CVE scan. `--report all` keeps every vulnerability. `--disable-node-collector` skips the privileged node Job, which checks node configuration and is not this image scan. The same command with `--format table --severity CRITICAL,HIGH` writes a shorter table.

The scan does not open the kind node root filesystem. A kernel CVE such as CVE-2026-98432 will not appear here. CVE-2026-123158 (OpenSSH) and CVE-2026-111497 (Brotli) were not present in these images.

Counts below are distinct CVE ids. The same Go CVE is counted once per workload even when several binaries in that image contain it. The machine-readable copy, with `InstalledVersion` on every row, is `posture-report-kind-global-chat-20261111T194343Z/trivy-vuln.json`.
